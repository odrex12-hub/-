# Компоновка АГД6.07.010 + ИИ-компьютер Firefly ROC-RK3588S-PC

Проверка размещения платы ИИ над платой авионики (этажерка). Файлы:

- `assembly_iso.png`, `assembly_side.png` — вид сборки;
- `AGD6_Firefly_assembly.step` — сборка целиком (плата со всеми компонентами + Firefly + крепёж), открывается во FreeCAD / SolidWorks / КОМПАС;
- `make_stack.py` — генератор модели Firefly и крепежа (параметры высот в начале файла).

| Параметр | Значение |
|---|---|
| Основание (пластина) | 130 × 160 × 2 мм |
| Стойки АГД6.07.010 | M3 × 8 мм, 4 шт. по отверстиям 50 × 110 мм (снизу детали ≤ 4.3 мм — разъёмы JST GH) |
| Зазор верх АГД6 → низ Firefly | 25 мм (самый высокий компонент — PS201/PS202 10.7 мм; ответные части разъёмов ≤ 14 мм) |
| Стойки Firefly | M3, 4 шт., 36.6 мм от основания, проходят снаружи платы АГД6 (5.5 мм от её длинных краёв) |
| Высота этажерки над основанием | ≈ 50 мм (с радиатором Firefly) |
| Габарит в плане | 130 × 160 мм (по основанию) |

Разъёмы Firefly (питание DC 5.5 × 2.1, LAN, USB) обращены к краю АГД6 с разъёмами XT30 — кабель питания
J202 -> DC-штекер ≤ 0.3 м, Ethernet ИИ — к J1006.

**ДОПУЩЕНИЯ (CHECK_DATASHEET Firefly):** модель Firefly габаритная — размер платы 118 × 111.6 мм по обзорам,
положение отверстий (3.5 мм от углов), набор и высоты разъёмов, радиатор 44 × 44 × 14 мм — предположение.
Проверить: координаты отверстий Firefly, не мешают ли стойки Firefly кабелям боковых разъёмов АГД6
(J401–J413, J1001–J1003), нужен ли вентилятор на радиатор при 14.4 W в закрытом отсеке.
