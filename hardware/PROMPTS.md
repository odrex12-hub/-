Проект: агро-гексакоптер X6. Локальная папка: F:\CDronePropeller 1.

KiCad 10, kicad-cli в PATH (C:\Program Files\KiCad\10.0\bin\).

Задача: объединить три платы KiCad (CAN-хаб, модуль ключей 12 V, плата сопряжения датчиков)

Прочитай первыми:

   и C3 (время сброса ИИ ~1 с). Убери пометки CHECK_DATASHEET, где подтверждено.

## 2. Универсальный промт для разработки печатной платы

Заполнить поля в квадратных скобках.

```
Ты — инженер-разработчик электроники. Разработай печатную плату в KiCad 10
от требований до производственных файлов. Работай в репозитории, папка hardware/<имя_платы>/.

1. НАЗНАЧЕНИЕ И ФУНКЦИОНАЛ
   - Назначение платы: [что делает плата]
   - Функции: [список функций]
   - Интерфейсы и разъёмы: [CAN / UART / Ethernet / USB / I2C / GPIO — с количеством]
   - Нагрузки: [что коммутирует, токи, напряжения]

2. ПИТАНИЕ
   - Вход: [напряжение, диапазон, источник]
   - Нужные шины: [12 V / 5 V / 3.3 V — ток на каждой]
   - Защита: обратная полярность, перенапряжение, предохранители, TVS на входе.

3. МЕХАНИКА
   - Габариты и контур: [размеры, вырезы, крепёжные отверстия, DXF если есть]
   - Максимальная высота компонентов: [мм], сторона монтажа: [одна / две]
   - Условия: вибрация, температура [диапазон], влага и химия [да/нет -> лак, IP-разъёмы]

4. ПРОИЗВОДСТВО
   - Производитель: [JLCPCB / PCBWay / Резонит], слоёв: [2/4/6], толщина меди: [1/2 oz]
   - Монтаж: [сам / заводской SMT] -> компоненты с наличием у [LCSC / Mouser / ЧипДип]
   - Типоразмер пассивных компонентов не меньше [0402/0603].

5. ПОРЯДОК РАБОТЫ (после каждого этапа — отчёт и вопросы ко мне)
   a) Структурная схема и бюджет мощности (таблица потребителей).
   b) Выбор ключевых компонентов с обоснованием и ссылками на datasheet.
   c) Принципиальная схема по листам -> ERC без ошибок.
   d) Стек слоёв, правила DRC под производителя, ширина дорожек по IPC-2221 для каждого тока.
   e) Расстановка компонентов (разделение силовой/аналоговой/цифровой частей, короткие контуры
      DC/DC, развязывающие конденсаторы у выводов) -> PNG-рендер до трассировки.
   f) Трассировка, полигоны земли, stitching vias, диф. пары с контролем импеданса -> DRC без ошибок.
   g) Выпуск: Gerber, сверловка, BOM с кодами поставщика, CPL, 3D STEP, PDF схемы, README
      с распиновкой разъёмов, порядком первого включения и тестовыми точками.

6. ПРАВИЛА
   - Не выдумывай параметры: чего нет в требованиях — помечай DATA_REQUIRED и спрашивай.
   - Каждое решение проверяй по datasheet, расчёты сохраняй в calculations.md.
   - Тестовые точки на всех шинах питания и ключевых сигналах, светодиоды питания, маркировка разъёмов.
   - Коммить после каждого этапа с понятным описанием.
```
